# ICTsol F1 開発方針

## アプリ概要

疲労度や予定状況を考慮して、利用者が取り組みやすいタスクを提案するスマホアプリを開発する。

## 技術構成

- スマホアプリ：Expo + React Native + TypeScript
- バックエンド：Python + FastAPI
- 生成AI：Python SDK
- データベース：まずは SQLite を候補とする

## 通信構成

```text
スマホアプリ → FastAPI → 生成AI API / データベース
```

APIキーはスマホアプリに置かず、バックエンドで管理する。

## 最初の完成条件

- スマホアプリが起動する
- FastAPI が起動する
- スマホアプリから FastAPI の `/api/health` または `/api/hello` を呼び出せる
- チーム全員が同じ手順で開発環境を起動できる
